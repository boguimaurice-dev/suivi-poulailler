# Carnet du Poulailler — Suivi de Rentabilité

Application web partagée pour le suivi de rentabilité des lots de volailles (chair et pondeuses).

## Données
Les données sont stockées dans Supabase (base partagée entre tous les membres de l'équipe).
Projet Supabase : `rtcnggurwwvanplkbygm`

## Déploiement
Ce dépôt contient un seul fichier `index.html` autonome (aucune installation, aucun build).
Vercel le sert tel quel dès que le dépôt est connecté.

## Mettre à jour l'app
1. Remplacez le contenu de `index.html` par la nouvelle version fournie
2. Committez et poussez (ou éditez directement depuis l'interface GitHub)
3. Vercel redéploie automatiquement en quelques secondes
